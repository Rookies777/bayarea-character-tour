# 湾区字游 · 一字一城

大湾区旅游文创互动 H5：拆字、解字、组字，集齐 11 座城市汉字，合成湾区字帖。

## 在线体验

- GitHub Pages：<https://rookies777.github.io/bayarea-character-tour/>
- 豆包在线版：<https://4m5gkpr5nw9t5.doubaoapps.com/app/app_17f3ukzzk2a>

## 玩法

| 环节 | 说明 |
| --- | --- |
| 拆字 | 将打散的部件归位，重组城市汉字 |
| 解字 | 查看字源 / 地标 / 非遗 / 食味 / 宜游 / 线路，点击卡片看图 |
| 组字 | 沿墨迹描红，一笔成字 |
| 湾区问答 | 看文旅线索猜城市，获取湾区文旅评级 |
| 集字 | 集齐 11 字合成湾区字帖，保存分享 |

## 覆盖城市

广州 · 深圳 · 香港 · 澳门 · 佛山 · 东莞 · 珠海 · 肇庆 · 江门 · 中山 · 惠州（每城一汉字：穗 圳 帆 莲 陶 香 珠 砚 碉 侨 湖）
